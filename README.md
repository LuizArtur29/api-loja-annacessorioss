## 📝 Sobre o Projeto

Este é um sistema de gestão completo (ERP) desenvolvido sob medida para a loja **Ana Acessórios**. O objetivo principal foi substituir processos manuais por uma solução digital robusta, permitindo o controlo de vendas, estoque, finanças e clientes em tempo real.

O projeto foi construído com foco em escalabilidade, segurança (JWT) e uma experiência de utilizador (UX) fluida.

---

## ✨ Funcionalidades Principais

- **📦 Gestão de Produtos:** Cadastro, edição e controlo de estoque com categorias.
- **💰 Fluxo de Vendas:** Registo de vendas com múltiplos itens, cálculo automático de totais e integração com estoque.
- **📊 Dashboard Inteligente:** Visualização de métricas de desempenho, comparação entre Vendas vs. Despesas e lucro líquido.
- **💸 Controlo Financeiro:** Gestão de despesas fixas e variáveis.
- **👤 Gestão de Clientes:** Base de dados para fidelização e histórico de compras.
- **🔐 Segurança:** Autenticação e autorização via JWT (JSON Web Token) com rotas protegidas no Frontend e Backend.

---

## 🛠️ Tecnologias Utilizadas

### Backend
- **Java 17** & **Spring Boot 3**
- **Spring Security** (Autenticação JWT)
- **Spring Data JPA** (Persistência de dados)
- **PostgreSQL** (Base de dados relacional)
- **Docker** (Contentorização para Deploy)

### Frontend
- **React.js** (Vite)
- **Axios** (Integração com API)
- **React Router Dom** (Navegação)
- **Styled Components / CSS Modules** (Estilização)
